# MovaEngine

Інструмент для локалізації відеоігор. 
На сьогоднішній день програма підтримує повністю або частково роботу з 20 ігровими рушіями (Unity, Unreal, GameMaker Studio, GodotEngine, Ren'Py та інші).
Можливості програми: відкриття ігрових архівів, створення зручної таблиці для локалізації або відкриття у простому редакторі, заміна векторних або редагування растрових шрифтів, оновлення ігрових файлів, створення готових патчів.

Робота з усіма іграми не гарантується, так як не всі ігри побудовані ідентично навіть на одному рушії (особливо це стосується старих ігор).

## Завантаження

Готову збірку програми можна завантажити на сторінці [Releases](https://github.com/Batyar-lv/MovaEngine/releases).

## Вимоги

- Windows 10/11
- .NET 8 Desktop Runtime

## Встановлення

1. Завантажте останній `.zip` архів зі сторінки Releases.
2. Розпакуйте архів у зручну папку.
3. Запустіть `MovaEngine.exe`.
